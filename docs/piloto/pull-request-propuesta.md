# Piloto interno RP/RV con política compartida, evidencias y cierre reproducible

La comparación previsional exponía modalidades y supuestos pendientes de validación especializada. Esta entrega limita pantalla, API y PDF a RP simple y RV inmediata teórica con datos ficticios, conserva el motor verificado y rechaza cláusulas, resultados precalculados y funciones restringidas también por HTTP.

Con saldo positivo y sin beneficiarios se muestran únicamente curvas RP calculadas con tres rentabilidades reales hipotéticas. Con beneficiarios se permite solo la comparación inicial. Todos los montos se presentan como aproximaciones, sin ofertas comerciales, certificación normativa ni conexión con SCOMP.

La entrega añade guía de instalación y demostración local, inventario y empaquetado determinista con exclusión de configuración privada, checklist de controles pendientes, capturas y PDF ficticios. La referencia funcional es `2dae5e0`; el cierre no amplía su alcance.

Validación del cierre:

- 195 pruebas del simulador; ocho pruebas del paquete.
- TypeScript, lint y compilación de producción webpack.
- 79 solicitudes HTTP y nueve escenarios de navegador en escritorio/móvil; avisos y bloqueos de API/PDF comprobados.
- Instalación aislada, comprobación del inventario y regeneración del comprimido.

Consultar [informe de cierre](cierre.md), [resultados del piloto](../piloto-resultados.md) y [matriz actuarial](../fase-4-matriz-trazabilidad.md).

Limitaciones: el CNU no reproduce íntegramente el Anexo 7 ni CNCM; no se seleccionan tasas normativas por fecha. No hay autenticación ni uso autorizado con datos reales. Garantías, aumentos, combinaciones y proyecciones familiares futuras permanecen bloqueados. La demostración comprobada es local; no se acredita seguridad de un despliegue público.
